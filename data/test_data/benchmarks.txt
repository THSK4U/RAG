vLLM Performance Benchmarks
============================

Model: Llama-2-7B-chat
Hardware: NVIDIA A100 80GB
Batch Size: 32

Throughput Results
------------------
Framework       Tokens/sec    Latency (p50)    Latency (p99)
vLLM            4,892         18 ms            34 ms
HuggingFace     1,204         72 ms            145 ms
DeepSpeed       2,318         39 ms            81 ms
TensorRT-LLM    5,100         17 ms            31 ms

Notes:
- All benchmarks use greedy decoding (temperature=0)
- Input length: 128 tokens, output length: 128 tokens
- Results may vary depending on hardware and software versions

Memory Usage
------------
vLLM uses PagedAttention which reduces GPU memory waste by up to 55%
compared to traditional contiguous KV cache allocation.

Peak GPU Memory:
- vLLM:             42 GB
- HuggingFace:      78 GB  (runs out of memory at batch size 32)
- HuggingFace (bs8): 38 GB

Concurrency Test
----------------
Concurrent users: 100
vLLM handled all 100 requests simultaneously using continuous batching,
while HuggingFace processed them sequentially, causing 8x higher latency.
